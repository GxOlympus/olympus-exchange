# Olympus Exchange

Static browser game for Monad with Reown AppKit wallet connection.

## Local Run

```bash
npm run dev
```

Open:

```text
http://127.0.0.1:5173
```

## Check

```bash
npm run check
```

## GitHub

Create an empty GitHub repository, then push this local project:

```bash
git remote add origin https://github.com/YOUR_USERNAME/olympus-exchange.git
git branch -M main
git push -u origin main
```

## Vercel

1. Open https://vercel.com/new
2. Import the GitHub repository.
3. Framework Preset: Other.
4. Build Command: leave empty.
5. Output Directory: leave empty.
6. Deploy.

After Vercel gives a production domain, add it to the Reown project dashboard and verify the domain.
